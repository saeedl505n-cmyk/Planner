# Plan-B Android — Version 0.3.0 (Quality Pass)

اپلیکیشن بومی اندروید با رابط فارسی و ذخیره‌سازی محلی. این پروژه هنوز نسخه آزمایشی است؛ تا زمانی که اجرای موفق CI و نصب روی گوشی تأیید نشده، آن را نسخه انتشار عمومی در نظر نگیر.

## قابلیت‌های فعلی

- داشبورد خلاصه وظایف، پروژه‌ها، یادداشت‌ها و عادت‌ها
- افزودن، تکمیل و حذف وظایف
- ایجاد پروژه و ذخیره توضیحات
- ساخت یادداشت و ذخیره متن آن
- ثبت روزانه عادت‌ها در Room
- تایمر تمرکز ۱۵، ۲۵ و ۴۵ دقیقه‌ای و ثبت جلسه کامل‌شده
- اهداف با مقدار هدف، واحد و پیشرفت دستی
- آمار پایه برای وظایف، عادت‌ها و جلسات تمرکز
- مهاجرت دیتابیس Room از نسخه ۱ به ۲
- راست‌چین‌کردن سراسری رابط و پشتیبانی از ارقام فارسی/عربی در ورودی مقدار هدف
- تایمر باقی می‌ماند اگر کاربر در حین جلسه بین زبانه‌های برنامه جابه‌جا شود
- GitHub Actions برای اجرای تست، Lint و ساخت APK آزمایشی

## ساخت APK از GitHub با گوشی

1. ZIP را دانلود و از حالت فشرده خارج کن.
2. **محتویات پوشه پروژه** را به ریشه مخزن GitHub منتقل کن؛ نباید فایل‌های پروژه یک پوشه اضافی پایین‌تر قرار بگیرند.
3. مطمئن شو فایل `.github/workflows/android-build.yml` در مخزن وجود دارد.
4. در GitHub وارد زبانه **Actions** شو و workflow با نام **Android CI** را انتخاب کن.
5. گزینه **Run workflow** را بزن یا یک commit به شاخه `main`/`master` ارسال کن.
6. اگر کار اجرا شد ولی شکست خورد، ابتدا لاگ مرحله قرمز را بررسی کن. اگر همه مراحل موفق شدند، از بخش **Artifacts** فایل `planb-debug-apk` را دریافت کن.

این workflow نسخه Gradle سازگار با Android Gradle Plugin را نصب می‌کند و به فایل Gradle Wrapper داخل پروژه وابسته نیست. Build واقعی در محیط فعلی این بسته اجرا نشده؛ موفقیت آن را فقط پس از سبزشدن workflow می‌توان تأیید کرد.

## محدودیت‌ها و کارهای باقی‌مانده

- تقویم جلالی کامل، انتخاب تاریخ شمسی، موعد وظیفه و یادآور هنوز وجود ندارد.
- تایمر با سرویس foreground و اعلان دائمی اجرا نمی‌شود؛ بسته‌شدن فرایند برنامه می‌تواند جلسه در حال اجرا را از بین ببرد.
- ویرایش و حذف پروژه‌ها، یادداشت‌ها، عادت‌ها و اهداف از رابط کامل نشده است؛ ویرایش وظایف هم اضافه نشده.
- اولویت در مدل وظیفه وجود دارد اما هنوز تجربه کاربری کامل ندارد.
- جست‌وجوی سراسری، فیلترها، مرتب‌سازی پیشرفته، نمای تقویم و برنامه‌ریزی هفتگی وجود ندارد.
- خروجی/بازیابی پشتیبان، همگام‌سازی ابری، قفل حریم خصوصی و سیاست روشن برای حذف داده‌ها هنوز پیاده‌سازی نشده‌اند.
- آمارها پایه‌ای‌اند و نمودار روند هفتگی/ماهانه ندارند.
- معماری ViewModel/Repository هنوز به‌طور کامل تفکیک نشده است.
- نسخه Debug برای آزمایش است؛ انتشار عمومی به امضای Release، آزمون روی دستگاه واقعی، بررسی دسترس‌پذیری و بازبینی حریم خصوصی نیاز دارد.
